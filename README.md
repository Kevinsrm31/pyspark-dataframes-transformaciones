# PySpark DataFrames — Transformaciones y Agregaciones

Caso práctico en PySpark (Apache Spark) sobre Databricks: transformaciones, agregaciones, agrupamientos y consultas SQL sobre un DataFrame, usando la API de DataFrames y Spark SQL.

## Contenido

- [`Proyecto_Final_PySpark_Databricks.ipynb`](./Proyecto_Final_PySpark_Databricks.ipynb) — notebook con el desarrollo completo, listo para correr en Databricks.
- **Artículo:** [PySpark en Apache Spark: transformaciones, agregaciones y consultas SQL sobre DataFrames](https://medium.com/@kevinsrm19/pyspark-en-apache-spark-transformaciones-agregaciones-y-consultas-sql-sobre-dataframes-0ea1ea038a9e) (Medium) — recorrido completo con código y resultado real de cada operación.

## Qué cubre

- Selección y filtrado de datos (`select`, `filter`)
- Transformación de columnas: agregar, renombrar, eliminar, calcular (`withColumn`, `withColumnRenamed`, `drop`)
- Agregaciones y estadísticas (`avg`, `sum`, `min`, `max`, `count`)
- Agrupamiento y clasificación por rangos (`groupBy`, `when`/`otherwise`)
- Consultas SQL directas sobre el DataFrame (`createOrReplaceTempView` + `spark.sql`)

## Tecnologías

Apache Spark · PySpark · Spark SQL · Databricks
